# Fotos reais

Cada pasta é um serviço (o nome da pasta é o slug do serviço em `src/data/servicos.ts`).
Coloque as fotos dentro da pasta certa; a primeira foto (ordem alfabética) é usada no site.
`equipe/` é a foto da equipe (topo da home e "Por que a Elite").

Para trocar uma foto já convertida, apague `src/assets/fotos/<pasta>.jpg` e rode `npm run build`.
